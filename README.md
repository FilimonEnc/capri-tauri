# Capri Desktop // Rust + Tauri v2 Edition ⚡

> **Fork & Rewrite Notice**  
> Этот проект является глубоким форком и полным переосмыслением оригинального [capri-desktop](https://github.com/mochiiwuff/capri-desktop).  
> Приложение было полностью переписано с Electron/Node.js на **Rust + Tauri v2** для достижения максимальной производительности, минимального потребления памяти и нативной интеграции с Windows Win32 API.

---

## 🚀 Ключевые особенности версии на Rust

1. **Движок Rust + Tauri v2**
   - **Легковесность**: потребление оперативной памяти снижено более чем в 3 раза (~80–90 МБ вместо 300+ МБ в Electron).
   - **Высокая плавность (120+ FPS)**: нативное отслеживание курсора и окон Windows через Win32 API в фоновом потоке без задержек и лагов на мониторах с высокой частотой обновления.
   - **Надежный клик-тру оверлей**: точечный хит-тестинг (`onPanel`, `capri.hit`, `onChip`) гарантирует, что оверлей на 100% прозрачен для кликов по фоновым окнам, IDE и браузерам, даже когда открыт чат.

2. **Маркетплейс кибер-навыков (Cyberware Marketplace)**
   - Встроенный стилизованный маркетплейс в неоновой эстетике *Cyberpunk: Edgerunners* на локальном HTTP-мосте (`http://127.0.0.1:47823/marketplace`).
   - Установка и горячее подключение модов прямо в биочип Капри без перезапуска приложения.

3. **Trauma Team Biomonitor // Биомонитор Хоста**
   - Честная диагностика ресурсов реального компьютера через системные Win32 API (`GlobalMemoryStatusEx`, `GetSystemTimes`, `GetSystemPowerStatus`, `GetTickCount64`):
     - Физическая занятая и доступная оперативная память хоста (ОЗУ в ГБ и %).
     - Реальная нагрузка на все ядра процессора (ЦП в %).
     - Статус питания (сеть / батарея с процентом заряда) и время непрерывной работы (аптайм).
     - Изолированный учет памяти самого процесса Capri.

4. **Интеллектуальный модуль цитат Найт-Сити**
   - Распознавание конкретных персонажей в запросах (*Джонни Сильверхенд, Дэвид Мартинес, Люси, Ребекка, Адам Смэшер, Бестия, Киви, Мейн, Ви*).

5. **Мультиплеер и интеграция с музыкой**
   - Нативная поддержка **Яндекс.Музыки** (`yandexmusic://`), **Spotify**, **YouTube Music**, **Apple Music** и **VK**.
   - Прямой поиск треков через API, автоматический запуск «Моей волны» и управление воспроизведением мультимедийными клавишами.

6. **Удобство запуска и распространения**
   - **Capri.exe (Portable Single-File)**: автономный запуск без внешних зависимостей (все DLL и `WebView2Loader` вшиты в launcher).
   - **Capri_0.5.0_Setup.exe**: готовый Windows NSIS инсталлятор.

## 🎭 Что умеет Капри

* **Реакция на AI-ассистентов**: Капри наблюдает за работой **Claude Code**, **Codex** или **Antigravity** — комментирует редактирование файлов, выполнение тестов, поиск и ошибки.
* **Интро с захватом экрана**: при запуске она эффектно появляется, хватаясь за границы монитора и разбивая экран глитчем.
* **Физика и взаимодействие**:
  * Капри можно хватать мышью, перетаскивать, бросать и ронять на пол или окна.
  * Приземление на верхние кромки окон Windows с реалистичной физикой и раскачиванием ног.
  * Вселение в окна (*Possess windows*) с разрядами красных молний.
* **Сон и биочип**: после периода бездействия Капри сворачивается в зеленую маску или уходит в биочип в углу экрана, просыпаясь при приближении курсора.
* **Большая сцена спутника**: анимация созвездий и отправки сигнала на орбитальный спутник.

## 🛠️ Сборка из исходников

### Требования
* **ОС**: Windows 10 / 11 (x64)
* **Rust**: `rustc` и `cargo` (версия 1.75+)
* **Node.js**: LTS версия (18+)
* **WebView2 Runtime**: установлен по умолчанию в Windows 10/11

### Инструкция по сборке

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/FilimonEnc/capri-tauri.git
   cd capri-tauri
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запуск в режиме разработки:
   ```bash
   npm run dev
   ```

4. Сборка релизного бандла:
   ```bash
   npx tauri build
   ```
   Или для сборки автономного лаунчера:
   ```bash
   cd launcher
   cargo build --release
   ```
